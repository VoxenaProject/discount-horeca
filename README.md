# HF CONCEPT — V8

Private working preview: https://discount-horeca-maquette.dejvi-prifti.chatgpt.site

## Source and build

- `public/`: frontend and the 1,364-product imported catalogue.
- `worker/handler.js`: server routes, rendered product pages, request API and private inbox.
- `scripts/build-worker.mjs`: embeds frontend assets into the dependency-free Worker ESM artifact.
- `worker/index.js` and `dist/`: generated by `npm run build`; do not edit directly.
- `.openai/hosting.json`: retained Sites project identity and `BUCKET` R2 binding.

Run `npm run build`, `npm test`, then `node scripts/validate-artifact.mjs`.
Local preview is started through `sites-preview start` and uses in-memory test storage, separate from production R2.

## Requests and operations

`/api/requests` validates and stores quote/appointment requests in R2. Product IDs and quantities are checked against the catalogue; prices and product names are populated server-side. Submissions use idempotency identifiers. Basic origin checks, a honeypot and rate limiting are included.

`/gestion` is the inbox. Server-side authorization requires the platform-authenticated owner email `dejvi_prifti@hotmail.com`. The owner can read requests and update follow-up status. A different account is denied even if signed in. Do not publish the preview or change ownership without reviewing this allowlist and the access policy.

No email provider is configured: requests are stored, but no email notification or automatic acknowledgement is sent. Monitor the inbox. No booking calendar exists yet: submitted dates are preferences only and must be confirmed by the team. No payment or order checkout is implemented.

## Product and campaign data

Product stock, price, delivery and warranty remain subject to confirmation. No reviews, supplier promises, compatible accessory SKUs or Black Friday discounts have been invented. The compact campaign banner links to a preparation page until real offers are supplied.

Product URLs `/produit/ID/slug` render content and product metadata on the server, redirect to their canonical URL, and appear in `/sitemap.xml`. Existing hash links continue working. `/robots.txt` blocks crawling while this site is a private preview; update it deliberately at public launch.

## Verification

Browser QA covered the product page, local quote submission, appointment form and 390 px mobile rendering. No local test request is migrated to production.
