# Discount Horeca — Maquette V1

Première étape : haut de l’accueil commercial, logo existant, palette bleu nuit / orange / blanc cassé, offres produits et mise en avant Maxima.

Ouvrir `index.html` dans un navigateur. Aucun build ni dépendance externe : les images sont intégrées.

## Interactions
Recherche sur les quatre produits, filtres Froid / Cuisson / Pizzeria, aperçu produit, sélection temporaire pour devis, retrait et total HT. La sélection ne persiste pas après rechargement. Aucune commande ou demande n’est transmise.

## Sources et limites
Produits, visuels, logo, prix HT, promotions et coordonnées repris de https://www.discounthoreca.be/fr/ le 26 octobre 2026. TTC calculés à 21 %. Exclusivité de distribution Maxima indiquée par le client ; périmètre contractuel à valider avant lancement. Les produits présentés ne sont pas attribués à Maxima. Gamme Maxima, catégories complètes, fiches techniques, panier marchand et paiement restent à construire.

## Vérifications
Syntaxe JavaScript, affichage desktop, recherche, filtres et sélection de devis. Maquette responsive ; aucune connexion à un back-office.
